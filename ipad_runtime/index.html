Arquivos Exportados

Os arquivos internos do app são salvos automaticamente no armazenamento seguro do Safari/PWA — você não gerencia pastas. Quando você exporta algo para o app Arquivos, cada artefato recebe um nome único com data/hora (AR10_CYBORG_TIPO_VERSAO_AAAAMMDD_HHMMSS.ext), então o Safari nunca pede para "substituir" e dois artefatos diferentes nunca colidem.

Nenhum arquivo exportado contém segredo, chave de API, credencial de corretora ou dado de conta real — só estado de diagnóstico local, estatística descritiva sintética e metadados de integridade.
