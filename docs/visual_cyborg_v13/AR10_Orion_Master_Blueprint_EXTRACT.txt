2. TOPOLOGIA DO ECOSSISTEMA MULTIAGENTE
O desenvolvimento e a execução do sistema são divididos em 5 Agentes de IA
Especializados:
[AGENTE 1] Sensory_Agent (Visão & Audição)
Escopo: Ingestão de dados HFT, WebSockets e APIs REST.
Padrão:Read-Only / Air-Gap. Este agente apenas escuta o mercado (Binance, OKX, On-chain,
X/Twitter). É proibido de ter credenciais de execução de ordens. 
[AGENTE 2] Cognitive_Agent (Córtex Neural)
Escopo: Processamento matemático e motor de decisão.
Padrão:Neuromorphic Fusion / HNSW Vector Embedding. Utiliza PyTorch com tensores
vetorizados. Sem loops 'for' no fluxo principal. Calcula a entropia do vetor e o nível de estresse
(Cortisol). 
[AGENTE 3] Motor_Agent (Vias Executoras)
Escopo: Roteamento de ordens para corretoras.
Padrão:Zero-Latency Execution Pipeline. Conecta-se via MT5 ou APIs Cripto (MEXC)
estritamente para envio de ordens LONG/SHORT e gerenciamento de travas (Circuit Breaker). 
[AGENTE 4] UI_Voice_Agent (Cockpit & Cyborg TTS)
Escopo: Interface de usuário, telemetria em tempo real e síntese de voz.
Padrão:Glassmorphism UI / Asynchronous WebSockets / Web Speech API. Responsável
pela renderização do painel no navegador e pela voz robótica local (latência zero, sem
dependência de APIs externas). 
[AGENTE 5] Core_Survival_Agent (Sistemas Vitais)
Escopo: Memória, estabilidade e sincronismo do sistema operacional.
Padrão:IPC Zero-Copy / Drift-Free Temporal Oscillator / Garbage Collection. Expurgador
linfático de memória (libera RAM/CUDA automaticamente) e relógio atômico interno.
