AR10_CYBORG_2_TECH_SOURCE_LIBRARY_V1

Catálogo de fontes técnicas (APIs públicas, SDKs, bibliotecas client-side) avaliadas para o Real Data Layer e adjacências do AR10 Cyborg 2.0 — iPad One-Tap Cloud Runtime. Cada entrada documenta URL, licença, risco, decisão (ADOPT_NOW / STUDY_ONLY / FUTURE / REJECT_FOR_NOW), impacto e um checklist de segurança contra a política do projeto.

1Propósito e honestidade de fonte

Este documento é um catálogo de avaliação, não um manifesto executado em runtime — nenhum arquivo .js do app lê ou depende deste HTML. URL e licença de cada item vêm do conhecimento geral sobre o projeto público citado; esta sessão não tem acesso de rede de sandbox para revalidar ao vivo cada link/licença no momento da escrita. Antes de qualquer adoção real (mudar ADOPT_NOW para código em produção), quem for integrar deve abrir o link, confirmar a licença vigente e a versão exata — a mesma régua de honestidade que o Real Data Layer aplica a conectores de mercado (nenhuma fonte é tratada como válida só por suposição) também vale para dependências de código.

Quatro das fontes abaixo (CoinGecko, Binance Spot público, MEXC público, importação local CSV/JSON) já têm código real em ipad_runtime/js/real-data/*.js, sondado e classificado em runtime pelo registry.js — ver ipad_runtime/configs/real-data-sources.default.json. As demais ainda não têm nenhuma linha de código no runtime.

10Workbox

GoogleChrome/workbox — toolkit para Service Worker

Tipo: biblioteca/runtime para Service Worker · github.com/GoogleChrome/workbox
REJECT_FOR_NOW
LicençaMIT
Host de redeNENHUM
Implementação real (equivalente já existente)ipad_runtime/service-worker.js — 70 linhas, escrito à mão, auditável de ponta a ponta

Motivo da rejeição: o Service Worker atual é deliberadamente pequeno e 100% legível em uma única leitura — inclusive a regra de segurança crítica "nunca intercepta cross-origin" (if (new URL(req.url).origin !== self.location.origin) return;) é uma linha auditável a olho. 15Regras que nenhuma adoção futura pode violar

Qualquer item que mudar de STUDY_ONLY/FUTURE para ADOPT_NOW em uma sessão futura continua sujeito às 14 leis de docs/READ_ONLY_MARKET_SAFETY.md e à lista de proibições explícitas desta missão:

order_send · newOrder · placeOrder · cancelOrder · endpoint de conta · endpoint privado · API secret · API key no frontend · segredo em localStorage · execução real · live trading · LLM enviando ordem · SDK inteiro de exchange · dado sintético rotulado como real.
