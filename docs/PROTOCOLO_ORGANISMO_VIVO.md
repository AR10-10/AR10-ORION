## Nota de implementação (honesta, adicionada por Claude Code)

Este documento é a carta de intenções do Operador — preservada aqui na
íntegra, verbatim. A tradução técnica real dela para o que uma sessão do
Claude Code de fato consegue cumprir está em `CLAUDE.md`, na raiz do
repositório: nenhum processo autônomo roda em segundo plano entre sessões
(este projeto não tem infraestrutura própria para isso), então "evolução
contínua" aqui significa, na prática, que TODA sessão futura que trabalhe
neste repositório lê `CLAUDE.md` automaticamente antes de começar — é o
mecanismo real de memória persistente entre sessões que existe de fato, e
é onde a disciplina descrita acima (pesquisar antes de construir, nunca
tratar uma entrega como definitiva, documentar o raciocínio e o que ficou
para depois) vira prática de engenharia real a cada tarefa, não uma
promessa que não pode ser cumprida literalmente.
